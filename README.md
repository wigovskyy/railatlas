# Атлас железных дорог

Интерактивная карта железнодорожных маршрутов: свои линии, станции, туннели, мосты и интересные места.

- Подложки Plain (Esri Light Gray), Terrain (Esri World Topo), Satellite (Esri Imagery), все без API-ключа, и слой Rail — вся железнодорожная сеть мира от OpenRailwayMap, серый и полупрозрачный.
- «Добавить маршрут»: точки ставятся на карте, линия прокладывается по рельсам из OpenStreetMap (через Overpass API) со всеми поворотами.
- После сохранения маршрута сайт находит вдоль него станции, туннели и мосты из OpenStreetMap.
- Импорт треков из Google Мои карты и Google Earth (KML/KMZ): линии становятся маршрутами, точки — объектами.
- `data.json` — опубликованные маршруты: их видит каждый посетитель при первом открытии. Правки посетителя хранятся в его браузере (localStorage). Для переноса есть экспорт и импорт JSON; `examples.json` — пример с тремя маршрутами.

## Общее хранение на GitHub Pages

На `*.github.io` сайт читает `data.json` прямо из репозитория, поэтому с любого компьютера видна одна и та же карта. Править может тот, у кого есть токен GitHub с правом записи: каждое сохранение — коммит в `data.json` на основной ветке.

Удобнее всего настроить вход через GitHub (кнопка в статусе внизу панели): инструкция в [auth/README.md](auth/README.md). Без него работает запасной способ с токеном:

1. Создайте токен: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access: Only select repositories → этот репозиторий. Permissions → Repository permissions → Contents: Read and write.
2. Откройте сайт, нажмите на статус «GitHub, только просмотр» внизу панели и вставьте токен. Статус сменится на «GitHub, можно править». Токен запоминается только в этом браузере; на другом компьютере его нужно ввести один раз.
3. Правки собираются и через пару секунд уходят одним коммитом. Если в это время файл изменили с другого компьютера, сайт берёт свежую версию и накладывает свои правки поверх.

Не публикуйте токен: с ним можно менять файлы репозитория. Отозвать его можно там же, где он создан.

Весь сайт — один файл `index.html`, сборка не нужна.

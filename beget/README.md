# RailAtlas на Beget (с серверным хранением)

1. В `api.php` замените `ЗАМЕНИТЕ_НА_СВОЙ_КЛЮЧ` на длинный случайный ключ (от 8 символов). Пока ключ не изменён, запись отключена.
2. Загрузите `index.html`, `api.php` и `data.json` в папку на сайте, например `public_html/railatlas/`.
3. Откройте `https://ваш-сайт/railatlas/`. Внизу карты статус «на сервере, только просмотр». Нажмите на него и введите ключ: появятся кнопки редактирования.
4. Данные лежат в `data/` рядом с `api.php` (по файлу на маршрут и объект). При первом запуске туда переносится `data.json`.

Папка `data/` закрыта от прямого доступа через `.htaccess`. Сам `index.html` работает и без сервера (тогда данные хранятся в браузере), в том числе на GitHub Pages.
